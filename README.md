# Tempo Coffee

Este proyecto es una app de e-commerce hecha con React para el trabajo final del curso.

La temática que elegí fue una tienda de café, donde se pueden ver productos, entrar al detalle, agregarlos al carrito y finalizar una compra.

## Lo que se puede hacer en la app

- Ver todos los productos
- Filtrar por categoría
- Ver el detalle de cada producto
- Elegir cantidad de productos
- Agregar productos al carrito
- Ver el carrito con subtotales y total
- Eliminar productos del carrito
- Vaciar el carrito completo
- Completar un formulario de compra
- Generar una orden con Firebase

## Tecnologías que usé

- React
- React Router Dom
- Bootstrap
- Firebase
- Firestore
- Vite

## Componentes principales

- NavBar
- CartWidget
- ItemListContainer
- ItemList
- Item
- ItemDetailContainer
- ItemDetail
- ItemCount
- Cart
- CartItem
- CheckoutForm
- Checkout

## Base de datos

En este proyecto usé Firebase Firestore para traer los productos y guardar las órdenes de compra.
